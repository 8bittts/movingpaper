# Design System

Brand assets, the status-item mark and the overlay style for MovingPaper.

## Marks

- The app icon is the color night-sky PNG, generated by `scripts/generate-app-icon.swift` into `build/MovingPaper.icns`; `build/movingpaper.png` is the same mark for the README.
- The menu-bar extra is the template SF Symbol `cloud.moon.fill`, drawn by `MenuBarIcon`, so it tints with the menu bar; the color PNG never appears in the status item.
- `scripts/generate-banner.swift` renders `build/banner.png`, and `build/movingpaper-dmg-background.png` with `build/dmg-background-opaque.png` back the DMG window.
- `build/yen.png` is the YEN credit image the README embeds.

## Overlay

`LoadingOverlayView` is the one SwiftUI surface: an on-brand shimmer pill in the night-sky palette that floats above all windows while a wallpaper loads.
It stays a brand element and is not restyled as a system material.

## Menu copy

Menu titles are formatted by `MenuBarLabelFormatter` and asserted through `MenuSnapshot` tests; all copy is English.
The menu never advertises Settings, because no preferences UI exists (`AGENTS.md`).
